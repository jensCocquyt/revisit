When remote teams run on empty

Two years into fully remote work, our team noticed something the dashboards did not show: people were tired in a way that a weekend did not fix. Calendars were packed from nine to six, and every question became a call.

We started tracking the signs. Cameras stayed off more often, replies came later in the evening, and the same few people answered every message in the shared channel. None of that is a performance problem; it is a load problem.

What helped was boring. We moved status updates to written notes, kept Wednesdays free of meetings, and agreed that nobody expects an answer outside working hours. Managers asked about workload in every one-to-one instead of only about progress.

Six months later the sick days dropped, and so did the number of meetings. The work did not slow down.
